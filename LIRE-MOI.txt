SITE DE MAXIME SALLÉ — FICHIERS POUR GITHUB

1. Décompressez le ZIP.
2. Dans votre dépôt GitHub, remplacez index.html par le nouveau fichier.
3. Ajoutez styles.css, script.js et le dossier images au même niveau.
4. Enregistrez avec Commit changes.

Ne téléversez pas le ZIP lui-même : téléversez son contenu.
Pour voir le site sur votre ordinateur, ouvrez index.html après décompression.
